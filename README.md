# Portal Pessoal Enzo — Dark Red

Dashboard pessoal em GitHub Pages com módulos de Financeiro, Dieta e Treino.

## Arquivos principais
- `index.html`: site completo.
- `.nojekyll`: evita processamento pelo Jekyll.
- `modelo_lancamentos_financeiros.xlsx`: modelo para importar lançamentos financeiros.
- `modelo_refeicoes_dieta.xlsx`: modelo para importar refeições.
- `modelo_treinos.xlsx`: modelo para importar treinos.

## Publicar no GitHub Pages
1. Envie estes arquivos para a raiz do repositório.
2. Vá em Settings > Pages.
3. Em Source, selecione Deploy from a branch.
4. Selecione `main` e `/ (root)`.
5. Aguarde o link ser publicado.

## Observação
Os dados ficam salvos no navegador de quem usa o site, de forma criptografada pela senha informada. Em repositórios públicos, não suba planilhas preenchidas com dados sensíveis.
