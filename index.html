Formato das planilhas

Use os modelos que deixei na aba Importar. Para valores, use número puro, sem R$. Para centavos, use ponto ou vírgula.

Financeiro: Data, Mês, Tipo, Bloco, Categoria, Item, Valor, Observações.

Dieta: Data, Refeição, Alimento, Quantidade, Calorias, Proteína, Carboidrato, Gordura, Água ml, Observações.
